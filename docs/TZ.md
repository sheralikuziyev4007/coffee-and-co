# Техническое задание
## Проект: Landing page + мини-админ панель для кафе "Coffee&Co"

---

## 1. Общее описание проекта

Требуется разработать одностраничный лендинг для кафе с возможностью управления меню через отдельную админ-панель. Владелец кафе должен иметь возможность самостоятельно добавлять, редактировать и удалять позиции меню без обращения к разработчику.

**Целевая аудитория:** посетители кафе, ищущие информацию о заведении и его меню.

---

## 2. Технический стек

- **Frontend:** React + TypeScript
- **Стилизация:** Tailwind CSS
- **Хранение данных:** localStorage (для MVP; в реальном проекте — backend + база данных)
- **Роутинг:** React Router
- **Деплой:** Vercel или Netlify

---

## 3. Функциональные требования

### 3.1 Публичная часть (лендинг)

**Страница должна содержать следующие секции:**

1. **Header** — логотип, навигационное меню (Главная, Меню, О нас, Контакты), кнопка "Забронировать столик"
2. **Hero-секция** — заголовок, подзаголовок, фоновое изображение, CTA-кнопка
3. **О нас** — краткий текст о кафе, 2-3 фотографии интерьера
4. **Меню** — карточки блюд/напитков, сгруппированные по категориям (Кофе, Десерты, Завтраки и т.д.), с фото, названием, описанием и ценой
5. **Отзывы** — слайдер или сетка с отзывами клиентов (имя, текст, рейтинг звёздами)
6. **Контакты** — адрес, телефон, часы работы, встроенная карта (можно статичное изображение карты), форма обратной связи
7. **Footer** — соцсети, копирайт, повторная навигация

**Обязательные функции:**
- Меню должно **подгружаться из localStorage** (те же данные, что редактируются в админ-панели)
- Фильтрация блюд по категориям (кнопки-табы над списком меню)
- Форма обратной связи с валидацией (имя, телефон/email, сообщение — все поля обязательны, email должен соответствовать формату)
- Адаптивная вёрстка: корректное отображение на мобильных (375px), планшетах (768px) и десктопе (1280px+)
- Плавная прокрутка к секциям при клике на пункты меню в Header

### 3.2 Админ-панель (защищённый раздел `/admin`)

**Функции:**
1. **Простая авторизация** — форма логин/пароль (можно захардкодить одну учётную запись для MVP, например login: `admin`, password: `admin123`), после входа — редирект на панель, без входа доступ к `/admin` закрыт
2. **Список позиций меню** — таблица со всеми блюдами: фото (миниатюра), название, категория, цена, кнопки "Редактировать" и "Удалить"
3. **Добавление новой позиции** — форма с полями: название, категория (select из списка), цена, описание, ссылка на изображение. Валидация всех полей.
4. **Редактирование позиции** — та же форма, но предзаполненная текущими данными
5. **Удаление позиции** — с подтверждением ("Вы уверены?")
6. **Выход из аккаунта** (logout)

**Важно:** изменения в админ-панели должны сразу отражаться на публичном лендинге (через общий localStorage).

## 4. Модель данных

```typescript
interface MenuItem {
  id: string;
  name: string;
  category: 'coffee' | 'desserts' | 'breakfast' | 'main';
  price: number;
  description: string;
  imageUrl: string;
}

interface Review {
  id: string;
  authorName: string;
  rating: number; // 1-5
  text: string;
}

interface ContactFormData {
  name: string;
  contact: string; // email или телефон
  message: string;
}
```

---

## 5. Нефункциональные требования

- Код должен быть разбит на переиспользуемые компоненты (не один большой файл)
- Использовать TypeScript-типизацию для всех props и данных (без `any`)
- Состояние меню управляется через Context API или простой state-менеджер (Zustand подойдёт)
- Проект должен быть загружен на GitHub с понятным README (описание, скриншоты, технологии, ссылка на демо)
- Обязателен деплой на Vercel/Netlify с рабочей ссылкой

---

## 6. Что оценивается (критерии готовности)

- [ ] Лендинг адаптивен и выглядит аккуратно на всех разрешениях
- [ ] Меню на лендинге синхронизировано с админ-панелью
- [ ] Форма обратной связи валидируется корректно
- [ ] Админ-панель защищена от неавторизованного доступа
- [ ] CRUD-операции (добавить/редактировать/удалить) работают без ошибок
- [ ] Код структурирован по компонентам, использует TypeScript
- [ ] Проект задеплоен и доступен по ссылке
